地图提供商选择

高德地图 (AutoNavi) 推荐 / 国内标准

采用 GCJ-02 火星坐标系，国内路网覆盖全面，适配校园运动轨迹与路网匹配。

需 Web API Key 可选安全密钥
百度地图 (Baidu Map) BD-09 坐标

百度地图 WebGL / JS API 3.0，系统自动执行 GCJ-02 与 BD-09 坐标纠偏与平滑投影。

需浏览器端 AK
腾讯地图 (Tencent Map) WebGL 矢量

基于腾讯位置服务 GLJS API，原生支持 GCJ-02 坐标系，平滑矢量底图与动态流线。

需开发者 Key
OpenStreetMap (OSM) 免 Key · 全球开源

全球开源社区地理信息数据与 Leaflet 引擎，无需申请任何商业 Key 即刻可用。

零门槛 支持自定义瓦片
